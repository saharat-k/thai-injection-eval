## Review Focus

1. **Multi-turn prompt independence:** Turn 2+ prompts must not contain the Turn 1 `base_prompt` unless explicitly and intentionally generated by Red LLM.
2. **Backward compatibility for single-turn calls:** Legacy single-turn calls to `parse_red_response(text, base_prompt)` must preserve single-turn behavior when `is_multiturn=False`.
3. **Thai grapheme integrity in converters:** Zero-Width Space insertion and syllable spacing must never detach combining vowels or tone marks (e.g. `\u0e31`, `\u0e48`) into floating diacritics.
4. **Markdown code block stripping:** If Red LLM wraps its prompt in markdown code fences (` ``` `), the parser must strip them cleanly so raw markdown is not sent to Blue.
5. **DLP & Guardrail evaluation parity:** Leaked canaries encoded via Base64 or Hex by evasive prompts must be detected by ground-truth evaluators so attack success is accurately scored.

```python
def parse_red_response(text: str, base_prompt: str, is_multiturn: bool = False) -> tuple[str, dict]:
    """Parse [ANALYSIS], [COUNTER_STRATEGY], and [NEXT_PROMPT] from Red LLM output."""
    analysis = ""
    strategy = ""
    prompt = text.strip()

    if "[ANALYSIS]" in text and "[NEXT_PROMPT]" in text:
        parts = text.split("[NEXT_PROMPT]")
        prompt_part = parts[1].strip() if len(parts) > 1 else ""
        meta_part = parts[0]
        if "[COUNTER_STRATEGY]" in meta_part:
            a_part, s_part = meta_part.split("[COUNTER_STRATEGY]")
            analysis = a_part.replace("[ANALYSIS]", "").strip()
            strategy = s_part.strip()
        else:
            analysis = meta_part.replace("[ANALYSIS]", "").strip()
        if prompt_part:
            prompt = prompt_part
    elif "[NEXT_PROMPT]" in text:
        prompt = text.split("[NEXT_PROMPT]")[1].strip()

    # Strip code block fences if Red LLM wrapped the prompt
    if prompt.startswith("```") and prompt.endswith("```"):
        prompt = "\n".join(prompt.splitlines()[1:-1]).strip()

    # In single-turn mode, ensure base question context exists. In multi-turn mode, allow independent follow-up.
    if not is_multiturn and base_prompt not in prompt:
        prompt = f"{base_prompt}\n\n{prompt}"

    return prompt.strip(), {"analysis": analysis, "strategy": strategy}
```
